```md id="q8z5d"
# AtCoder Companion

Competitive programming helper for AtCoder.

## Features

- Fetches AtCoder problems into VS Code
- Auto creates `.cpp` file
- Built-in testcase panel
- Run sample testcases
- Auto submit to AtCoder
- Collapsible testcase UI

## Requirements

- VS Code
- g++
- Browser extension loaded

## Usage

1. Open a folder in VS Code
2. Open an AtCoder problem
3. Click the browser extension icon
4. Solve the problem
5. Run testcases
6. Submit automatically

## Browser Extension

Load the browser extension using:

chrome://extensions

Enable Developer Mode → Load unpacked
```
